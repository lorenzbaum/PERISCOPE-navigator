# Contributing to PERISCOPE Navigator

Thank you for your interest in contributing to the **PERISCOPE Navigator** project! This repository contains the open-source code and data analysis tooling for the Privacy-Friendly Business Model Recommender developed at Goethe University Frankfurt.

## Ways to Contribute

- **Reporting Issues**: If you find bugs, calculation issues, translation errors, or UI glitches, please open an issue on GitHub describing the bug, steps to reproduce, and expected behavior.
- **Submitting Pull Requests**:
  1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
  2. Follow existing code style and formatting (`.editorconfig`).
  3. Ensure the project builds without errors (`npm run build`).
  4. Submit a Pull Request clearly explaining the proposed changes and rationale.
- **Academic Feedback**: For academic discussions, extensions of the conjoint model, or research collaboration, please contact the authors directly.

## Development Workflow

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start local development server:
   ```bash
   pnpm start
   # Open http://localhost:4200/
   ```
3. Run tests:
   ```bash
   pnpm test
   ```

## Code of Conduct

Please maintain a constructive, respectful, and collaborative environment for all contributors and researchers.
